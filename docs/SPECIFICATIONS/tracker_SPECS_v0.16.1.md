## 1. 概述

### 1.1 背景

v0.16.0 在生产（EX1 项目）暴露出两个图表截图问题：

1. **正确性**：Chart.js 默认动画 1000ms，导出在切换后 300ms 截图，定格"最终标签 + 动画中途柱体"的中间帧——feature 图标签远离柱体、p0p1 图 "100%" 标签配 ~70% 柱高（BUG-114）。
2. **可读性**：标签 11~12px 在 ~1380px 宽 canvas 上，嵌入 PPT 后有效字号 ~4pt；p0p1 截图宽高比与 PPT 图位严重不匹配；"100%" 标签与顶部 legend 重叠（BUG-115）。

### 1.2 功能列表

| # | 功能 | 说明 |
|---|------|------|
| 1 | 图表导出渲染模式 | 导出期间动画时长归零（瞬时最终状态）+ 刻度/图例字号放大，三条导出路径统一接入 |
| 2 | 导出几何固定 | 容器宽度/高度按 PPT 图位宽高比固定（feature 1200px、p0p1 1000×500px） |
| 3 | 标签字号放大 | 导出模式 feature/p0p1 标签 18px bold，标题 16px |
| 4 | p0p1 标签方案乙 | ≥90% 白字柱内（横排/竖排自适应），<90% 柱顶外侧；legend 碰撞根除 |
| 5 | 100% 参考虚线 | p0p1 新增目标参考线（对齐样张） |
| 6 | 防裁切 | feature X 轴 grace 15% + p0p1 layout 顶部留白 |

## 2. 需求详情

### 2.1 REQ-CHART-101: 导出渲染模式

- 全局标志 `chartExportMode`，由 `setChartExportMode(enabled)` 控制：
  - `Chart.defaults.animation.duration = 0 / 1000`
  - `Chart.defaults.font.size = 13 / 12`
- `applyExportGeometry(type)` / `restoreExportGeometry()`：导出时固定容器几何（p0p1: 1000px、其他: 1200px）。
- 接入点：
  - `exportProjectPackage`（材料包）：捕获循环前置位，finally 中复位
  - `exportAllCharts`（批量）：循环前置位，结束后复位
  - `exportChart`（单张）：置位后重渲染当前图表再截图，截完恢复页面视图

### 2.2 REQ-CHART-102: p0p1 标签与参考线

- 标签分级（导出 18px / 页面 11px bold）：
  - `value ≥ 90` 且柱宽 ≥ 文本宽+8：柱内顶部横排白字
  - `value ≥ 90` 且柱宽不足：柱内顶部竖排白字（-90° 旋转）
  - `value < 90`：柱顶外侧深色字
- 参考线：100% 处灰色虚线（#6c757d, dash [6,4]）
- `layout.padding.top`：导出 26 / 页面 18，避让 legend
- X 轴模块名拥挤时 `maxRotation: 45`

### 2.3 REQ-CHART-103: feature 图可读性

- 标签导出 18px / 页面 12px bold，行内垂直间距随字号自适应（±0.6×fontSize）
- X 轴 `grace: '15%'` 防最大柱标签裁切
- 标题导出 16px
